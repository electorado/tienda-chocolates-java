# Tienda de Chocolate

## Descripción del Proyecto

Este proyecto es una aplicación de consola en Java para la gestión de una tienda de chocolate. Permite la administración de clientes, la de un catálogo de chocolates y el registro de ventas. El programa está diseñado para ser un ejercicio práctico de los módulos profesionales de programación y entornos de desarrollo.

### Funcionalidades

El sistema ofrece los siguientes menús interactivos:

* **Gestión de clientes**: Alta, baja, modificación, búsqueda por DNI y listado de clientes.

* **Gestión de productos**: Alta de chocolates, listado del catálogo y búsqueda por porcentaje de cacao y origen.

* **Realizar venta**: Proceso para crear una nueva venta, seleccionando un cliente y los productos.

* **Mostrar ventas**: Visualización de todas las ventas, filtradas por cliente y mostrando el total de cada venta.

## Requisitos para Compilar y Ejecutar

* **JDK 17 o superior**: Asegúrate de tener el Kit de Desarrollo de Java instalado.

* **Maven**: Este proyecto utiliza Maven para la gestión de dependencias y la construcción.

* **IDE**: Este proyecto ha sido desarrollado en IntelliJ IDEA.

## Instrucciones de Uso

1. **Clona el repositorio** desde GitHub.

2. **Abre el proyecto** en tu IDE de preferencia. IntelliJ IDEA reconocerá automáticamente la configuración de Maven.

3. **Ejecuta la clase `Main`** para iniciar el programa.

4. Sigue las opciones del menú en la consola para interactuar con la aplicación.
